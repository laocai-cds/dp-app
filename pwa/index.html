1. Token gqtthc

PWA không nhúng được trang gqtthc như app cũ nên cần lấy token đăng nhập từ trang gqtthc (token chỉ sống khoảng 30 phút, hết hạn thì lấy lại).

Cách lấy token
  1. Cách nhanh (dấu trang): kéo nút Lấy token gqtthc lên thanh dấu trang (hoặc bấm rồi tự tạo dấu trang, dán mã vào ô địa chỉ). Mở trang gqtthc.dcs.vn đã đăng nhập, bấm dấu trang đó, token sẽ tự chuyển sang trang này.
  2. Cách thủ công: trên máy tính, mở gqtthc.dcs.vn đã đăng nhập → F12 → Application → Local Storage → dòng token → sao chép giá trị → dán vào ô trên.
  3. iPhone: app cài trên Màn hình chính có bộ nhớ riêng, dùng cách sao chép mã rồi bấm Dán.
